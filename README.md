## Selected projects

### [UAE Expat Navigator](https://github.com/samm12331231/uae-expat-navigator)

A document-grounded assistant for UAE government service questions. Retrieves information from official PDFs and includes tools for eligibility checks and fee calculations.

**Stack:** Python · FastAPI · LangChain · ChromaDB

### [BullRun](https://github.com/samm12331231/BullRun)

An experimental options paper-trading system combining agent workflows, deterministic risk checks, human approval, and plain-language trade explanations.

**Stack:** Python · Next.js · Alpaca

### [UAE EcoVision](https://github.com/samm12331231/ecovision)

A computer-vision application for satellite and aerial imagery. Combines land-cover segmentation, object detection, and change detection with an interactive dashboard.

**Stack:** Python · PyTorch · SegFormer · YOLOv8 · OpenCV · FastAPI · Streamlit

### [Heatwatch](https://github.com/samm12331231/heatwatch)

A hackathon prototype exploring heat-risk monitoring for youth athletics, with weather-based estimates, scheduling recommendations, and an auditable decision trail. Includes a historical replay demo.

**Stack:** Python · Streamlit · SQLite
